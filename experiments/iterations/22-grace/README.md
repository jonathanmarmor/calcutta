# Grace and Grain

One-version permission for ornaments/passing tones; short flourishes; replace held retuning with breaths or fixed common tones.

[audio](calcutta_grace.mp3) · [midi](calcutta_grace.mid)

[Composition brief](BRIEF.md) · [Manifest and SHA-256 hashes](manifest.json)

frozen source and score available; external sound engines required.

Browse [frozen source](source/) or download [the original archive](source.zip). From the repository root, run `python experiments/reproduce.py 22-grace prepare`, then use the snapshot’s own README/listening guide inside the prepared directory. `--list` prints entry points; `score` runs the known composer when a command has been verified. Archived audio is the historical reference: native plugin/platform variations can change rendered samples.
